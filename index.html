Codewars — "Sum of Digits / Digital Root" (6 kyu)

Repeatedly sum the digits of a positive integer until a single digit is left. For example, 942 → 9+4+2=15 → 1+5=6. A small piece of number theory — the part of my mathematics degree that turned out to be the most fun in JavaScript. 

const digitalRoot = (n) => {
        while (n > 9) {
            n = String(n)
            .split('')
            .reduce((sum, digit) => sum + Number(digit), 0);
        }
        return n;
        };

        console.log(digitalRoot(942)); // 6
